# 6. Макеты экранов / Screen layouts

Four roles, one visual language: a header with the role name, a list of cards on the left (or on
top on a phone), the request card with the status badge, and a single accent colour that always
means "action available to you".

## 6.1 Единый стиль / Design tokens

Значения живут в одном файле — `frontend/src/styles/tokens.css` (BL-T5); компоненты используют
только `var(--*)`, «магических» цветов в них нет. Палитра берёзовая: тёплый кремовый фон,
белая бумага, тёмный текст «кора», свежая зелень листвы и золото осени для декора.

| Токен | Значение | Где используется |
| --- | --- | --- |
| `--color-bg` | `#F6F0E2` (берёзовая кора) | фон страницы |
| `--color-surface` | `#FFFBF2` | карточки, формы |
| `--color-surface-alt` | `#F0E7D4` | шапки таблиц, полосы списка |
| `--color-text` | `#2B2A28` (кора) | основной текст |
| `--color-muted` | `#635E53` | адрес, дата, подписи |
| `--color-primary` | `#5DB13A` (листва) | маркеры, иконки, акценты |
| `--color-primary-dark` | `#3E7D26` | фон основной кнопки, hover тёмного акцента |
| `--color-primary-ink` | `#356C1F` | зелёные ссылки и активная навигация |
| `--color-secondary` | `#F2B134` (золото осени) | только декор на светлом фоне |
| `--color-border` | `#E4D9BF` | границы и разделители |
| `--color-danger` | `#C42B31` | ошибки, «Отклонена», опасное действие |
| `--radius-md` / `--radius-lg` | `12px` / `16px` | поля ввода / карточки |
| `--tap` | `44px` | минимальная цель нажатия (доступность) |
| `--content-width` | `1120px` | ширина контента на ноутбуке |
| шрифт / font | Inter (текст), Nunito (заголовки) | весь интерфейс |
| сетка / grid | 1 колонка, далее `min-width: 560 / 720 / 900 px` | адаптивность phone first |

Контраст (WCAG AA, 4.5:1): белый текст на `--color-primary-dark` — 5.0:1, на
`--color-primary-deep` — 7.1:1; `--color-muted` на фоне — 5.7:1; `--color-primary-ink` на
фоне — 5.6:1. Золото на светлом фоне используется только как подсветка и точки, не как текст.

Status colours (see `frontend/src/components/StatusBadge.tsx` and `--status-*` в `tokens.css`).
Цвет статуса — это цветная точка и мягкий фон; рядом всегда стоит подпись (RU + EN), поэтому
цвет никогда не является единственным признаком, а текст остаётся тёмным (AA):

| Статус | Цвет | Подпись |
| --- | --- | --- |
| `NEW` | синий `#3B82F6` | Новая / New |
| `VERIFIED` | бирюзовый `#14B8A6` | Проверена / Verified |
| `IN_PROGRESS` | оранжевый `#F59E0B` | В процессе / In progress |
| `PENDING` | фиолетовый `#8B5CF6` | Ожидает / Pending |
| `RESOLVED` | зелёный `#22A55A` | Выполнена / Completed |
| `REJECTED` | красный `#E5484D` | Отклонена / Rejected |

## 6.3 Оператор / Operator

```
┌──────────────────────────────────────────────┐
│ CityFix        Оператор · Анна С.     Выйти  │
├──────────────────────────────────────────────┤
│ Статус [Новая ▾]  Служба [Все ▾]  [Найти]    │
├──────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────┐ │
│ │ №1042  Яма на дороге         [ Новая ]   │ │
│ │ Житель: Иван Петров · ул. Ленина, 15     │ │
│ │            [ Проверить ]  [ Отклонить ]  │ │
│ └──────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

The operator's actions open a dialog: choose the service (`Исполнитель`) and a comment →
`NEW → VERIFIED` (FR-3, TC-5). `Отклонить` asks for a mandatory reason from the list
(дубль, не наша зона, мало информации, спам, другое) → `REJECTED` (TC-10, TC-11).

## 6.4 Исполнитель / Executor

```
┌──────────────────────────────────────────────┐
│ CityFix      Исполнитель · Служба «Дороги»   │
├──────────────────────────────────────────────┤
│ [ В процессе (3) ] [ Ожидают (2) ] [ Готово ]│
│ ┌──────────────────────────────────────────┐ │
│ │ №1031  Не горит фонарь   [ В процессе ]  │ │
│ │ ул. Мира, 4 · с 13.11.2026               │ │
│ │    [ Выполнено ] [ Пауза ] [ Вернуть ]   │ │
│ └──────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

`Выполнено` требует комментария; переход `IN_PROGRESS → RESOLVED` пишет запись истории, которую
проверяет TC-6. `Пауза` (`PENDING`) требует причины и необязательной даты возобновления (TC-13),
`Вернуть` отдаёт заявку оператору (`→ VERIFIED`). Кнопки — не меньше 44 px в высоту.

## 6.6 Состояния интерфейса / UI states

| Состояние | Как выглядит |
| --- | --- |
| загрузка / loading | скелетон из 3 карточек и подпись «Загрузка…» |
| пусто / empty | «Заявок пока нет» + кнопка «Новая заявка» для жителя |
| ошибка / error | красный блок с текстом ошибки сервера и кнопкой «Повторить» |
| нет прав / forbidden | «Недостаточно прав для этого действия» (после `403`) |
| истёк токен / expired | сообщение «Сессия истекла, войдите снова» и переход на вход |
| подтверждение / confirm | карточка «Выполнена»: «Подтвердить результат» / «Проблема осталась» (BL-R1) |
| причина отказа / reject | обязательный список причин, для «Другое» — комментарий (TC-10) |

## 6.7 Адаптивность / Responsiveness

- один столбец до 720 px, карточки на всю ширину, кнопки не меньше 44 px по высоте;
- карта занимает 40vh на телефоне и 320 px на ноутбуке;
- горизонтальная прокрутка таблиц запрещена — списки всегда карточками;
- проверяется на телефоне, ноутбуке и в двух браузерах (вид проверок «устройства», section 10).
